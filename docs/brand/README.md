# Easy Suite brand assets

Generated by `scripts/brand/kit_v2.py`, which imports the shared Easy Suite brand scripts (`easy-suite-brand/`
`suite12_v2.py`, read-only) and writes only into this folder and `web/public/`. Same frame, palette and fonts across
all thirteen tools; only the icon and accent colour change. Easy Kit uses sky `#5fd3f3` and a toolbox with a play
triangle (the kit that runs a game); its banner art is the generated VillageDemo in Godot, and the social preview
puts Godot gameplay next to the Pixi title screen and Thai dialogue.

| File | Use |
|---|---|
| `banner-kit.png` (1280×320) | README header |
| `social-kit.png` (1280×640) | GitHub social preview: Settings → General → Social preview → Upload |
| `logo-kit.png` (240×240), `logo-kit-48.png`, `logo-*-96.png` | Tool logos; the `-96` set is used by the suite table |

Regenerate after a new preview: `python3 scripts/brand/kit_v2.py --shots /workspace/easykit-preview/shots`.
Fonts in the art: Press Start 2P and Kanit (both SIL OFL 1.1). v2 style: subtle green accent and a light
8-point star (girih) pattern on the teak, cream and gold palette.
