# Credits

## Easy Kit

* Code (CLI, MCP server, dashboard, template glue in `templates/*/godot/kit/` and `templates/*/pixi/`): MIT.
* The template's kit strings (`templates/*/strings/`) and template settings are written for this repo and dedicated
  to the public domain (CC0 1.0), like the other Easy Suite samples.
* Content rules for templates: no depiction of the Prophet or of sacred figures; no Quran, scripture or Arabic
  calligraphy; no synthesized adhan; halal-appropriate food; Thai village, Malay-Muslim and Chinese-Thai life side by
  side. A test (`test/template.test.ts`) scans every template file for these.

## What a generated game contains

Everything in a generated project comes from the Easy tools at the commit `easykit doctor` reports, under their
own terms: samples and generated art, sound and music are CC0 1.0; **Kanit** (Cadson Demak) is SIL OFL 1.1 and is
copied with its `OFL.txt` by the tools. Character sheets are generated into the user's project and are never part
of this repository.

* **PixiJS v8** (MIT, © PixiJS contributors) — `pixi.min.js` is copied from `node_modules/pixi.js` into each web build.
* Godot projects target **Godot 4.3+** (MIT); nothing from the engine is included.

## Brand art

`docs/brand/` is generated by `scripts/brand/kit_v2.py` on top of the shared Easy Suite brand scripts. Fonts in the
art: Press Start 2P and Kanit (both SIL OFL 1.1). The banner and screenshots in `docs/assets/` are captures of the
generated VillageDemo.
